Pro Tip for Realistic Portraiture

Midjourney v6: Character Reference (--cref)

Easiest
  1. Take a clear, well-lit, front-facing selfie of yourself without heavy filters or sunglasses.
  2. Upload your selfie to Discord, right-click the image, and choose Copy Link.
  3. Paste this copied prompt into Midjourney, and append: --cref <your_photo_link> --cw 25
  4. --cw 25 focuses primarily on your facial features while letting the prompt style your hair, outfit, and background!

Flux.1: PuLID & InstantID

Highest Quality
  1. Use ComfyUI, Fooocus, or web tools like Replicate with the Flux PuLID model.
  2. Load your portrait as the identity reference image with weight set to 0.75 - 0.85.
  3. Paste this customized prompt into the positive conditioning node for instant photo-realism.

Stable Diffusion / ReActor Node

Flexible
  1. Generate the image using this prompt in A1111, Forge, or ComfyUI.
  2. Enable the ReActor extension (InsightFace) with your face photo set as the target.
  3. Enable CodeFormer or GFPGAN face restoration at 0.6 weight for crystal-clear skin texture.
