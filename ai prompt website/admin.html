Supabase Database & Cloud Storage

Link your live Supabase database and storage bucket to persist your prompts, track copy analytics, and store uploaded image files.

How to link your Supabase account:

  1. Create a free project at supabase.com.
  2. Go to Project Settings > API and copy the Project URL and anon public key.
  3. Go to the SQL Editor in Supabase, open sql/supabase_schema.sql from this project, and click RUN.
  4. Paste your credentials above and click Test Connection. Done!
